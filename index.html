Core Trigonometric Definitions & Reciprocals

Primary Ratios (SOH-CAH-TOA)

Sine (sin θ) = Opposite / Hypotenuse

Cosine (cos θ) = Adjacent / Hypotenuse

Tangent (tan θ) = Opposite / Adjacent = sin θ / cos θ

Reciprocal Ratios

Cosecant (csc θ) = 1 / sin θ = Hypotenuse / Opposite

Secant (sec θ) = 1 / cos θ = Hypotenuse / Adjacent

Cotangent (cot θ) = 1 / tan θ = Adjacent / Opposite

10 Step-by-Step Problem Solving Examples

Example 1: Using Pythagorean Theorem

Problem: In a right-angled triangle, leg a = 6 and leg b = 8. Find the hypotenuse c.

Solution:
1. c² = a² + b²
2. c² = 6² + 8² = 36 + 64 = 100
3. c = √100 = 10
Answer: Hypotenuse c = 10

Example 2: Finding Sine Ratio

Problem: Right triangle has opposite side = 5 and hypotenuse = 13. Find sin θ and csc θ.

Solution:
1. sin θ = Opp / Hyp = 5/13
2. csc θ = 1 / sin θ = 13/5
Answer: sin θ = 5/13, csc θ = 13/5

Example 3: Finding Cosine and Adjacent Side

Problem: Hypotenuse = 10 and cos θ = 0.8. Find the adjacent side length.

Solution:
1. cos θ = Adj / Hyp → 0.8 = Adj / 10
2. Adj = 0.8 × 10 = 8
Answer: Adjacent side = 8

Example 4: Using Tangent to Find Opposite Side

Problem: Adjacent side = 12 and tan θ = 3/4. Find the opposite side.

Solution:
1. tan θ = Opp / Adj → 3/4 = Opp / 12
2. Opp = 12 × (3/4) = 9
Answer: Opposite side = 9

Example 5: Finding Missing Leg via Pythagorean Theorem

Problem: Hypotenuse c = 15 and leg a = 9. Find leg b.

Solution:
1. b² = c² - a² = 15² - 9² = 225 - 81 = 144
2. b = √144 = 12
Answer: Leg b = 12

Example 6: Reciprocal Secant Calculation

Problem: If cos θ = 4/5, find sec θ.

Solution:
1. sec θ = 1 / cos θ
2. sec θ = 1 / (4/5) = 5/4
Answer: sec θ = 5/4

Example 7: Cotangent Calculation

Problem: If tan θ = 7/24, find cot θ.

Solution:
1. cot θ = 1 / tan θ
2. cot θ = 24/7
Answer: cot θ = 24/7

Example 8: Finding Angle using Inverse Sine

Problem: In a right triangle, sin θ = 0.5. Find angle θ.

Solution:
1. θ = arcsin(0.5)
2. θ = 30° (or π/6 rad)
Answer: θ = 30°

Example 9: Using Pythagorean Identity

Problem: If sin θ = 3/5 in Quadrant I, find cos θ.

Solution:
1. sin² θ + cos² θ = 1 → (3/5)² + cos² θ = 1
2. 9/25 + cos² θ = 1 → cos² θ = 16/25
3. cos θ = √(16/25) = 4/5
Answer: cos θ = 4/5

Example 10: Complete Triangle Evaluation

Problem: Angle θ = 45° and adjacent side = 7. Find opposite side and hypotenuse.

Solution:
1. tan(45°) = 1 → Opposite = Adjacent = 7
2. Hypotenuse c = √(7² + 7²) = √98 = 7√2
Answer: Opposite = 7, Hypotenuse = 7√2
