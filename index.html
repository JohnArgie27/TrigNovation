Core Trigonometric Definitions & Reciprocals

Primary Ratios (SOH-CAH-TOA)

Sine (sin θ) = Opposite / Hypotenuse

Cosine (cos θ) = Adjacent / Hypotenuse

Tangent (tan θ) = Opposite / Adjacent = (sin θ) / (cos θ)

Reciprocal Ratios

Cosecant (csc θ) = 1 / (sin θ) = Hypotenuse / Opposite

Secant (sec θ) = 1 / (cos θ) = Hypotenuse / Adjacent

Cotangent (cot θ) = 1 / (tan θ) = Adjacent / Opposite

10 Step-by-Step Right Triangle Problem Solving Examples

Example 1: Using Pythagorean Theorem

Problem: In a right-angled triangle, leg a = 6 and leg b = 8. Find the hypotenuse c.

Solution:
1. c² = a² + b²
2. c² = 6² + 8² = 36 + 64 = 100
3. c = √100 = 10
Answer: Hypotenuse c = 10

Oblique Triangles, Law of Sines, Cosines & Heron's Formula

Law of Sines

Used for AAS, ASA, or SSA triangles.

a / sin(A) = b / sin(B) = c / sin(C)
Law of Cosines

Used for SAS or SSS triangles.

c² = a² + b² - 2ab · cos(C)
Heron's Formula (Area)

Area given 3 side lengths (a, b, c).

s = (a + b + c) / 2
Area = √(s(s - a)(s - b)(s - c))
