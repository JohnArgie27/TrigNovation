Core Trigonometric Definitions & Reciprocals

Primary Ratios (SOH-CAH-TOA)

Sine (sin θ) = Opposite / Hypotenuse

Cosine (cos θ) = Adjacent / Hypotenuse

Tangent (tan θ) = Opposite / Adjacent = sin θ / cos θ

Reciprocal Ratios

Cosecant (csc θ) = 1 / sin θ = Hypotenuse / Opposite

Secant (sec θ) = 1 / cos θ = Hypotenuse / Adjacent

Cotangent (cot θ) = 1 / tan θ = Adjacent / Opposite

10 Step-by-Step Right Triangle Problem Solving Examples

Example 1: Using Pythagorean Theorem

Problem: In a right-angled triangle, leg a = 6 and leg b = 8. Find the hypotenuse c.

Solution:
1. c² = a² + b²
2. c² = 6² + 8² = 36 + 64 = 100
3. c = √100 = 10
Answer: Hypotenuse c = 10

Example 2: Finding Sine Ratio

Problem: Right triangle has opposite side = 5 and hypotenuse = 13. Find sin θ and csc θ.

Solution:
1. sin θ = Opp / Hyp = 5/13
2. csc θ = 1 / sin θ = 13/5
Answer: sin θ = 5/13, csc θ = 13/5

Example 3: Finding Cosine and Adjacent Side

Problem: Hypotenuse = 10 and cos θ = 0.8. Find the adjacent side length.

Solution:
1. cos θ = Adj / Hyp → 0.8 = Adj / 10
2. Adj = 0.8 × 10 = 8
Answer: Adjacent side = 8

Example 4: Using Tangent to Find Opposite Side

Problem: Adjacent side = 12 and tan θ = 3/4. Find the opposite side.

Solution:
1. tan θ = Opp / Adj → 3/4 = Opp / 12
2. Opp = 12 × (3/4) = 9
Answer: Opposite side = 9

Example 5: Finding Missing Leg via Pythagorean Theorem

Problem: Hypotenuse c = 15 and leg a = 9. Find leg b.

Solution:
1. b² = c² - a² = 15² - 9² = 225 - 81 = 144
2. b = √144 = 12
Answer: Leg b = 12

Example 6: Reciprocal Secant Calculation

Problem: If cos θ = 4/5, find sec θ.

Solution:
1. sec θ = 1 / cos θ
2. sec θ = 1 / (4/5) = 5/4
Answer: sec θ = 5/4

Example 7: Cotangent Calculation

Problem: If tan θ = 7/24, find cot θ.

Solution:
1. cot θ = 1 / tan θ
2. cot θ = 24/7
Answer: cot θ = 24/7

Example 8: Finding Angle using Inverse Sine

Problem: In a right triangle, sin θ = 0.5. Find angle θ.

Solution:
1. θ = arcsin(0.5)
2. θ = 30° (or π/6 rad)
Answer: θ = 30°

Example 9: Using Pythagorean Identity

Problem: If sin θ = 3/5 in Quadrant I, find cos θ.

Solution:
1. sin² θ + cos² θ = 1 → (3/5)² + cos² θ = 1
2. 9/25 + cos² θ = 1 → cos² θ = 16/25
3. cos θ = √(16/25) = 4/5
Answer: cos θ = 4/5

Example 10: Complete Triangle Evaluation

Problem: Angle θ = 45° and adjacent side = 7. Find opposite side and hypotenuse.

Solution:
1. tan(45°) = 1 → Opposite = Adjacent = 7
2. Hypotenuse c = √(7² + 7²) = √98 = 7√2
Answer: Opposite = 7, Hypotenuse = 7√2

Oblique Triangles: Law of Sines & Law of Cosines

Law of Sines

Used when solving AAS, ASA, or SSA (Ambiguous Case) triangles.

      a                  b                  c      
─────────── = ─────────── = ───────────
  sin(A)            sin(B)            sin(C)  
Law of Cosines

Used when solving SAS (Side-Angle-Side) or SSS (Side-Side-Side) triangles.

c² = a² + b² − 2ab · cos(C)
              a² + b² − c²
cos(C) = ───────────────
                  2ab

10 Step-by-Step Oblique Triangle Worked Examples

Example 1 (Law of Sines - AAS): Finding a Side

Problem: In ΔABC, ∠A = 30°, ∠B = 45°, and side a = 12. Find side b.

Solution:
1. Apply Law of Sines:
       a              b
─────────── = ─────────── ⇒ 12 / sin(30°) = b / sin(45°)
  sin(A)          sin(B)
2. b = [ 12 · sin(45°) ] / sin(30°) = [ 12 · 0.7071 ] / 0.5 = 16.97
Answer: Side b ≈ 16.97
Example 2 (Law of Sines - ASA): Finding a Side

Problem: In ΔABC, ∠A = 50°, ∠C = 60°, and side c = 15. Find side a.

Solution:
1. Apply Law of Sines: a / sin(A) = c / sin(C) ⇒ a / sin(50°) = 15 / sin(60°)
2. a = [ 15 · sin(50°) ] / sin(60°) = [ 15 · 0.7660 ] / 0.8660 = 13.27
Answer: Side a ≈ 13.27
Example 3 (Law of Cosines - SAS): Finding Third Side

Problem: In ΔABC, side a = 7, side b = 10, and ∠C = 60°. Find side c.

Solution:
1. Apply Law of Cosines: c² = a² + b² − 2ab · cos(C)
2. c² = 7² + 10² − 2(7)(10) · cos(60°) = 49 + 100 − 140(0.5) = 149 − 70 = 79
3. c = √79 = 8.89
Answer: Side c ≈ 8.89
Example 4 (Law of Cosines - SSS): Finding an Angle

Problem: In ΔABC, side a = 5, side b = 7, and side c = 10. Find ∠C.

Solution:
1. Apply Law of Cosines: cos(C) = (a² + b² − c²) / (2ab)
2. cos(C) = (5² + 7² − 10²) / [2(5)(7)] = (25 + 49 − 100) / 70 = −26 / 70 = −0.3714
3. ∠C = arccos(−0.3714) = 111.8°
Answer: Angle ∠C ≈ 111.8°
Example 5 (Law of Sines): Finding an Angle

Problem: In ΔABC, side a = 10, side b = 14, and ∠A = 35°. Find ∠B.

Solution:
1. sin(B) / b = sin(A) / a ⇒ sin(B) = [ 14 · sin(35°) ] / 10 = [ 14 · 0.5736 ] / 10 = 0.8030
2. ∠B = arcsin(0.8030) = 53.4°
Answer: Angle ∠B ≈ 53.4°
Example 6 (SAS Triangle Area): Finding Area

Problem: Find the area of ΔABC where side a = 8, side b = 11, and ∠C = 50°.

Solution:
1. Area = ½ · a · b · sin(C)
2. Area = 0.5 · 8 · 11 · sin(50°) = 44 · 0.7660 = 33.70
Answer: Area ≈ 33.70 square units
Example 7 (Law of Cosines - Navigation): Distance Problem

Problem: Two ships leave port at an angle of 58°. Ship 1 travels 40 km, Ship 2 travels 55 km. Find the distance d between them.

Solution:
1. d² = 40² + 55² − 2(40)(55) · cos(58°)
2. d² = 1600 + 3025 − 4400(0.5299) = 4625 − 2331.56 = 2293.44
3. d = √2293.44 = 47.89 km
Answer: Distance d = 47.89 km
Example 8 (Law of Sines - Complete Triangle): ASA Case

Problem: Solve ΔABC given ∠A = 40°, ∠B = 70°, and side c = 12.

Solution:
1. ∠C = 180° − (40° + 70°) = 70°
2. side a = [ c · sin(A) ] / sin(C) = [ 12 · sin(40°) ] / sin(70°) = [ 12 · 0.6428 ] / 0.9397 = 8.21
3. side b = [ c · sin(B) ] / sin(C) = [ 12 · sin(70°) ] / sin(70°) = 12
Answer: ∠C = 70°, a = 8.21, b = 12
Example 9 (Law of Cosines - SSS): Smallest Angle

Problem: Find the smallest angle in a triangle with sides a = 6, b = 8, and c = 12.

Solution:
1. The smallest angle ∠A is opposite the shortest side a = 6.
2. cos(A) = (b² + c² − a²) / (2bc) = (8² + 12² − 6²) / [2(8)(12)] = (64 + 144 − 36) / 192 = 172 / 192 = 0.8958
3. ∠A = arccos(0.8958) = 26.4°
Answer: Smallest angle ∠A ≈ 26.4°
Example 10 (Ambiguous Case - SSA): Two Triangles Check

Problem: In ΔABC, side a = 12, side b = 16, and ∠A = 30°. Determine possible values for ∠B.

Solution:
1. sin(B) = [ b · sin(A) ] / a = [ 16 · sin(30°) ] / 12 = [ 16 · 0.5 ] / 12 = 8 / 12 = 0.6667
2. ∠B₁ = arcsin(0.6667) = 41.8°
3. ∠B₂ = 180° − 41.8° = 138.2° (Valid since ∠A + ∠B₂ = 30° + 138.2° = 168.2° < 180°)
Answer: ∠B can be 41.8° or 138.2°
